## 个人项目

### NexusAgent

> 基于 LangGraph 的多智能体协作平台 · 个人独立开发 · 2026.08 – 2026.10

普通的 ReAct 循环在多步骤、多工具的任务里很难控制，出了问题也不好中途干预。这个项目主要是想把 Agent 的执行过程做得更可控、可追踪。

- **流程编排**：用 LangGraph 的 StateGraph 把 Agent 流程建成有向图，配合 Checkpointer 把每一步的状态存下来；执行高风险工具前用 `interrupt` 暂停，人工确认后通过 `Command.resume` 从断点继续
- **检索与记忆**：Qdrant 向量检索 + BM25 关键词检索两路召回，用 RRF 合并排序，改善专有名词、冷门知识召回不到的问题；对话中提到的用户偏好会自动记下来，后续对话再注入 Prompt
- **可观测与容错**：记录每次工具调用的耗时、Token 消耗和状态快照，方便排查和统计成本；工具报错时把错误结构化地反馈给模型让它自己修正，配合白名单校验和超时中断，避免卡死
- **MCP 与前端**：实现了一个 MCP 客户端，统一接入本地和远程工具服务；前端是 React 19 写的三栏工作台，支持 SSE 流式输出和思维链折叠展示，也能接入飞书 / 企业微信机器人

**技术栈**：Python、FastAPI、LangGraph、Qdrant、BM25、React 19、TypeScript、Docker

### CloudCLI（灵犀）

> 基于 Claude Agent SDK 的跨端编程助手 · 2026.05 – 2026.10

想把命令行里的 AI 编程助手搬到网页和桌面端，同时能接入自己写的工具。

- **Agent 与 MCP**：基于 `@anthropic-ai/claude-agent-sdk` 封装了多会话的运行环境；自己写了行情订阅分析和多媒体处理两个 MCP 服务（stdio 通信），Agent 可以按需调用
- **网页终端**：用 node-pty + xterm.js（开启 WebGL 加速）+ WebSocket 做了双向的终端流，命令行交互可以完整地显示在网页上；同一套代码打包出 Web 版和 Electron 桌面版，带文件树和代码 Diff 查看
- **会话管理**：用 SQLite 保存会话上下文，不同工作区（Worktree）之间状态互相隔离；写了运维脚本做依赖检查、进程异常自动拉起和日志汇总

**技术栈**：Node.js、Express、TypeScript、React 18、Electron、SQLite、WebSocket

### 多租户 SaaS 系统（实习）

> 邯郸泓曦软件开发有限公司 · AI 应用 / 全栈开发实习生 · 2025.08 – 2026.09

参与公司给客户定制的多租户运营中台和移动端系统。

- **业务开发**：负责租户权限体系、动态表单和部分核心业务模块，跟进了多个定制项目的上线和客户验收
- **性能优化**：针对历史订单、多维度统计这类慢查询调整了复合索引和查询方式；加了 Redis 多级缓存，用分布式锁防止缓存击穿，核心接口的 P99 延迟降低了 45% 左右
- **支付对接**：对接微信支付、银联支付和短信服务；用数据库状态机管理订单状态，加上定时对账和失败重试，处理网络不稳定、回调丢失时的状态不一致问题
- **研发效率**：用 Claude Code、Cursor 辅助生成单元测试和做接口契约校验，减少重复的回归测试工作

### 美业多商户管理系统（接单）

> 独立开发与部署 · 2026.04 – 2026.06

给美业门店做的多商户管理系统，带一个 AI 经营助手。

- **架构**：Spring Boot 3.5 模块化单体，Sa-Token 做鉴权；多个商户共用一套库表，通过 MyBatis-Plus 拦截器自动带上租户 ID 实现数据隔离；排班、客流高峰这类查询加了 Redis 缓存
- **AI 经营助手**：接入大模型 Function Calling，把流水汇总、会员画像、业绩统计等查询封装成工具，店长直接用自然语言提问，模型自动调用对应的统计接口返回结果

**技术栈**：Spring Boot 3.5、Vue 3、MySQL、Redis、Sa-Token、OpenAI Function Calling、Docker
