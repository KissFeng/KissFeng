## 个人项目

### NexusAgent

> 基于 LangGraph 的多智能体协作平台 · 独立开发 · 2026.08 – 2026.10

传统 ReAct 循环在多步骤、多工具任务中执行过程不透明，且难以在中途进行人工干预。本项目以显式状态编排为核心，提升 Agent 执行过程的可控性与可追溯性。

- **状态编排与人工审批**：使用 LangGraph StateGraph 对 Agent 执行流程建模，结合 Checkpointer 持久化各节点状态；在高风险工具调用前通过 `interrupt` 挂起流程，经人工确认后由 `Command.resume` 从断点恢复执行
- **混合检索与长期记忆**：结合 Qdrant 向量检索与 BM25 关键词检索进行双路召回，并采用 RRF 融合排序，改善专有名词与长尾知识的召回效果；对话中的用户偏好会被提取沉淀，并在后续会话中注入 Prompt
- **可观测性与容错**：记录工具调用耗时、Token 消耗及状态快照，用于问题排查与成本统计；工具异常时将错误信息结构化反馈给模型以进行自我修正，并配合白名单校验与超时熔断，防止执行失控
- **MCP 客户端与交互界面**：实现 MCP 客户端以统一接入本地及远程工具服务；前端基于 React 19 构建三栏式工作台，支持 SSE 流式输出与思维链折叠展示，并可对接飞书 / 企业微信机器人

**技术栈**：Python、FastAPI、LangGraph、Qdrant、BM25、React 19、TypeScript、Docker

### CloudCLI（灵犀）

> 基于 Claude Agent SDK 的跨端编程助手 · 2026.05 – 2026.10

将命令行形态的 AI 编程助手扩展至 Web 与桌面端，并支持接入自研工具服务。

- **Agent 运行环境与 MCP 集成**：基于 `@anthropic-ai/claude-agent-sdk` 封装多会话运行容器；自研行情订阅分析与多媒体处理两个 MCP 服务（stdio 通信），供 Agent 按需调用
- **Web 终端仿真**：基于 node-pty、xterm.js（WebGL 加速）与 WebSocket 构建双向终端数据流，在网页中完整还原命令行交互；同一套代码同时交付 Web 版与 Electron 桌面版，并集成文件树与代码 Diff 查看
- **会话管理与运维**：使用 SQLite 存储会话上下文，实现多工作区（Worktree）间的状态隔离；编写运维脚本，支持依赖检测、进程异常自动拉起与日志聚合

**技术栈**：Node.js、Express、TypeScript、React 18、Electron、SQLite、WebSocket

### 美业多商户管理系统（外包）

> 独立开发与部署 · 2026.04 – 2026.06

面向美业门店的多商户管理系统，集成 AI 经营助手。

- **系统架构**：基于 Spring Boot 3.5 的模块化单体架构，使用 Sa-Token 鉴权；多商户共享库表，通过 MyBatis-Plus 拦截器自动注入租户 ID 实现行级数据隔离；针对排班、客流高峰等场景引入 Redis 缓存
- **AI 经营助手**：基于大模型 Function Calling，将流水汇总、会员画像、业绩统计等查询封装为工具，管理者可使用自然语言提问，由模型调用相应统计接口并返回结果

**技术栈**：Spring Boot 3.5、Vue 3、MySQL、Redis、Sa-Token、OpenAI Function Calling、Docker
